# Biblioteca API

API REST para la gestión de una biblioteca.

## Tecnologías

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- JUnit
- Mockito
- Git
- GitHub

## Endpoints

### Libros

GET /books

GET /books/{id}

GET /books/search?title=java

GET /books/search?author=martin

POST /books

PUT /books/{id}

DELETE /books/{id}
